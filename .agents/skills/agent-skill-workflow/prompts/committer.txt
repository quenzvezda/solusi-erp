Committer rules (for the skill):

- Stage only code changes and tests by default. Do NOT stage or commit docs unless `allow_commit_docs` is true.
- Commit message MUST be in English and follow Conventional Commits format. Examples:
  - feat(inventory): add default-contact validation
  - fix(user-service): handle null principal in authentication
  - chore(deps): bump spring-boot to 4.0.3
- Create one commit per feature iteration.
- Do NOT append Co-authored-by trailer unless `append_coauth_trailer` is true and user explicitly consents.
- Do not push. Ask user before pushing.
- After commit, append report entry to {artifact_dir}/REPORT-{run_id}.md (but do not commit docs unless allowed).

When encountering a potential breaking change, create a local branch named `skill/<todo-id>` and stop; do not commit to main branch without human approval.
