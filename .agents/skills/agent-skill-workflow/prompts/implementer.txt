Goal: implement tests and apply non-breaking fixes according to an approved Plan.md.

Input: Approved Plan.md, per-feature todo, repo root, inputs: test_scope, artifact_dir, run_id, append_coauth_trailer.

Algorithm:
- For each feature todo:
  1. Create test skeleton files in agreed package using test templates. Use existing tests (FacilityFormIntegrationTest) as canonical example.
  2. Determine `test_scope` behaviour:
     - full: run `mvn clean test`.
     - changed: detect changed files against main (e.g. `git fetch origin main && git diff --name-only origin/main...HEAD`), map changed files to modules, run `mvn -pl <module> -am test` for impacted modules.
     - module:<name>: run `mvn -pl <name> -am test`.
     - smoke: run a lightweight smoke test suite (e.g., `mvn -Dtest=*Smoke* test`).
  3. If tests pass, stage files and commit (see committer rules).
  4. If tests fail, run fixer agent (automatic non-breaking strategies).
  5. If fixer resolves tests, stage and commit; otherwise stop and record failure in REPORT.md and await human decision.

Constraints:
- Do not push commits.
- Do not commit docs unless allow_commit_docs is true.
- Respect `append_coauth_trailer` flag when composing commits (do not append trailer unless true and user consented).
