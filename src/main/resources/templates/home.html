Procure-to-Pay Business Flow

The landing page highlights an end-to-end ERP scenario, from purchasing through inventory movement, vendor settlement, and accounting journal generation.

Purchase Order

Create supplier orders with tax calculation, approval status, and line totals.

Goods Receipt

Receive items from purchase documents and connect them to inventory valuation.

Stock Movement

Track on-hand quantity, serialized stock, bins, and chronological stock cards.

Vendor Bill

Record payable invoices from received goods with tax and settlement status.

Vendor Payment

Allocate payments to bills and keep outstanding balances visible.

Journal Entry

Generate balanced debit and credit entries from operational transactions.

ERP Modules in Action

Selected screens show the system as a working ERP case study, not only a technology demo.

Procurement to Receiving

Purchase orders move into goods receipt with billing status, serial numbers, and journal links.

Inventory Visibility

Stock reports expose on-hand, reserved, available, and in-transit quantities across items.

Accounts Payable Settlement

Vendor bills demonstrate partial settlement, debit memo application, and outstanding balances.

Vendor Payment Allocation

Payments are allocated to vendor bills while keeping paid and outstanding amounts visible.

Accounting Integration

Operational documents produce balanced journal entries using configured accounting schemas.

Enterprise Patterns Covered

The project also demonstrates controls expected in business software: approvals, security, auditability, and multilingual UI.

Approval Workflow

Centralized approval management tracks document type, assignee, status, and approval history.

Role-Based Access Control

Fine-grained permissions secure menus, pages, and actions using Spring Security authorities.

Audit Trail and Localization

Every major record keeps audit metadata while the UI supports English and Indonesian content.

Engineering Stack

Built as a server-rendered ERP application with modern Java, controlled schema migration, and reusable UI patterns.

Backend Core

Spring Boot 4.0.3 (Java 21)

Java 21 backend with Clean Architecture, DDD, CQRS, validation, mapping, and domain-focused modules.

Database & Migration

MariaDB & Flyway

Versioned relational schema with Flyway migrations for repeatable application setup.

Security

Spring Security 6+

Stateful session security with authority-based access control for ERP workflows.

Frontend UI

Thymeleaf, Tabler, HTMX

Server-side rendering with Bootstrap 5, Tabler components, HTMX fragments, and AJAX forms.

Reporting

JasperReports & Apache POI

Reporting foundation for PDF and Excel outputs across operational data.

Visualization

ApexCharts & Tabler Icons

Dashboard-ready visual components and iconography aligned with the Tabler admin interface.
