# Product Guide: Solusi Program ERP

## Initial Concept
Enterprise Resource Planning System for Learning.

## Vision
To build a modular, high-quality, and comprehensive ERP system using Java 21 and Spring Boot. The project serves as both a functional software for a software house and a learning resource for understanding complex ERP workflows, particularly the bridge between operational modules (Sales, Procurement, Inventory) and financial accounting (Journal Entries, COGS/HPP, Profit & Loss).

## Target Users
- **Software House Developers:** To serve as a base for custom ERP solutions.
- **Learners:** Programmers looking to master ERP logic, particularly the accounting schema and COGS calculation.

## Core Goals
- **Code Clarity:** Maintain a modular and easy-to-understand code structure.
- **Feature Completeness:** Implement end-to-end ERP workflows, including Sales, Procurement, and Inventory.
- **Consistent Architecture:** Ensure every feature follows a unified code style and architectural pattern.
- **Bridge Operations to Finance:** Clearly demonstrate how operational actions (like stock adjustments) translate into financial data (Journal Entries, COGS).

## Priority Features
### 1. Inventory Management
- Product and category management.
- Warehouse hierarchy (Facilities, Containers, Grids).
- Unit of Measure (UOM) management.
- Stock adjustments and transfer orders.

### 2. Operational Flows (Planned)
- **Sales Flow:** Order to invoice.
- **Procurement Flow:** Requisition to payment.

### 3. Financial Integration (Deep Dive Needed)
- **Accounting Schema:** Automated journal entries for operational transactions.
- **COGS (HPP):** Accurate calculation of Cost of Goods Sold.
- **Profit & Loss:** Generation of reports based on operational and financial data.

## User Experience
- **Primary Access:** Web-based interface.
- **Interface Goal:** Professional, consistent, and easy to navigate for back-office operations.
