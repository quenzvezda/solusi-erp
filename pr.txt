# PR Suggestion

## Title
feat(security/ui): integrate user-party relationship and modernize UX with dynamic themes & AJAX forms

## Description
This PR strengthens the core security model by establishing a direct link between Users and Parties, while significantly elevating the user experience through AJAX-based form modernization, a dynamic visual theme engine with automated locale synchronization, and critical dark mode refinements.

### 🚀 Key Features & Refactorings
- **User-Party Integration**: Established a first-class `@OneToOne` relationship between `User` and `Party` entities. This includes immutability logic to prevent unlinking once set, a specialized lookup for available parties, and a confirmation-driven selection UI.
- **AJAX Form Modernization**: Overhauled `erp-form-handler.js` to standardize JSON/AJAX submissions across core modules (Profile, Role, Party, Permission). Added robust handling for multi-checkbox and multi-select data aggregation.
- **Dynamic Theme Engine**: Introduced "Warm" and "Green" visual themes. These aren't just color swaps; they utilize a variable-driven CSS architecture that adjusts primary accents and background tints while maintaining a consistent dark-sidebar layout.
- **Automated Locale Sync**: Implemented `LocaleSyncInterceptor` to automatically persist a user's language preference to the database based on request headers, ensuring a seamless localized experience across different devices and sessions.
- **UX Refinements**: 
    - Standardized action icons for the Stock Adjustment list to match the Product module's UX.
    - Resolved TomSelect "double-text" visual bugs and improved the re-search experience.
    - Streamlined the Profile view by removing redundant role sections and utilizing dynamic i18n labels.

### 📚 Documentation
- **`docs/spec/i18n-guide.md`**: Added technical documentation for the automated database-level locale synchronization.
- **`docs/spec/ui-standards.md`**: Updated the UI standards with mandates for dark mode compatibility and the new theme-aware CSS variable system.

### 🛠️ Technical Details
- Leveraged `GlobalModelAttributeAdvice` to inject the user's latest theme and language preferences into all UI models globally.
- Refactored `tomselect-custom.css` to use CSS variables, allowing dropdowns and controls to adapt automatically to any selected theme.
- Implemented backend validation in `UserService` to enforce party immutability.
- Migrated `ProfileController` to support API-driven updates and localized synchronization.
