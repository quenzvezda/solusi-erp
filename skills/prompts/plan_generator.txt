Goal: produce a Plan.md draft from a context bundle.

Input: context bundle JSON from discover agent, user constraints (allow_commit_docs boolean), default test package layout.

Tasks:
1. Generate a Plan.md with sections: Overview, Scope, Acceptance criteria, Test package layout, Implementation steps (detailed), Todos with ids, and REPORT.md instructions.
2. For each template/feature, create a todo entry (id: inventory-<feature>-form-tests) and suggested test filenames and packages.
3. Keep the plan actionable and minimal. Include human checkpoint for plan approval.

Output: Plan.md text and a list of todos (id, title, description).
